AI EduAsistent – Project Management Documentation
Project Overview

AI EduAsistent is a web platform designed to help primary school teachers create creative, curriculum-aligned teaching materials using OpenAI GPT-3 technology.
The platform also includes educational modules to enhance teachers’ understanding of artificial intelligence and its responsible use in education.

Project Management Objectives

This project was developed as part of the Project Management course to demonstrate the full life cycle of software project planning, execution, and control according to PMBOK and Agile (Scrum) standards.

Main objectives:

Apply recognized Project Management methodologies (Agile and Scrum).

Create complete project documentation, including Charter, WBS, RACI Matrix, Stakeholder Map, Risk and Budget Plans.

Define KPIs and OKRs to evaluate project performance and outcomes.

Ensure alignment between technical, pedagogical, and strategic goals.

Project Structure
Section	Description
1. Project Charter	Business Case, Objectives (OKRs), Scope, Stakeholders, Technical Architecture
2. SWOT Analysis	Analysis of internal and external project factors
3. Work Breakdown Structure (WBS)	Hierarchical task decomposition and deliverables
4. Product Roadmap & Timeline	Six Agile sprints covering development to deployment
5. User Requirements Specification (URS)	Functional and non-functional requirements
6. Resource Breakdown Structure (RBS)	Human, technical, and software resources
7. Stakeholder Map & RACI Matrix	Roles, responsibilities, and communication flow
8. Risk Plan	Risks, probability, mitigation strategies
9. Budget Control Plan	Cost tracking, red flags, contingency strategies
10. Metrics & KPIs	Quantitative and qualitative success indicators
11. Development Process	Agile methodology, tools, and retrospective summary
Tools and Technologies

Methodology

The project followed the Agile Scrum framework with six two-week sprints.
Key practices included:

Daily stand-ups and sprint retrospectives

MoSCoW method for prioritization

Continuous user testing and feedback collection

OKR-based performance tracking
